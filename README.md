# 🚦 Movilidad Urbana y Productividad Económica en Ciudades de Latinoamérica

### Análisis de datos con Python | Data Analytics Portfolio

## 📌 Resumen del proyecto

Este proyecto analiza la relación entre la movilidad urbana y los indicadores económicos de distintas ciudades latinoamericanas, con el propósito de identificar patrones de congestión vehicular y explorar cómo estos pueden relacionarse con variables de productividad y desarrollo urbano.

A través de Python y técnicas de análisis exploratorio de datos (EDA), se realiza la preparación, limpieza, transformación e integración de distintas fuentes de información.

## 🎯 Objetivo de negocio

Evaluar cómo los indicadores de movilidad urbana se relacionan con variables económicas y demográficas de las ciudades, para generar información que pueda apoyar la toma de decisiones sobre inversión en infraestructura de transporte.

### 3. Integración de información
- Preparación de las fuentes de movilidad y economía.

### 5. Visualización e interpretación
